# StudentVoice

GitHub Pages-ready version of the supplied StudentVoice website. The original page design and browser-side interactions are preserved; the embedded CSS and JavaScript have been separated into `style.css` and `script.js`.

## Publish with GitHub Pages
1. Upload `index.html`, `style.css`, and `script.js` to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then save.

Note: GitHub Pages hosts static HTML/CSS/JavaScript only. Any server/database-dependent features in a project require a separately hosted backend.
